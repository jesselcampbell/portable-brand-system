## Roles

| Role | Who | Can |
| ---- | --- | --- |
| Owner | | Approve changes; final say on the brand |
| Steward | | Maintain the system, review proposals, publish versions |
| Contributor | | Propose changes and bring work back |

## What changes how

| Change | Approved by | Version bump |
| ------ | ----------- | ------------ |
| Strategy (identity, positioning) | Owner | Major |
| New or changed guidance, new output guide | Steward + Owner | Minor |
| Corrections and clarifications | Steward | Patch |
| Profile facts | Steward | Patch |
